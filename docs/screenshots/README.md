# Screenshot Guide

This directory is reserved for verified product captures used in the public portfolio release. Capture screenshots from the running application rather than adding mockups or placeholder images.

## Recommended Capture Set

- `default-analysis.png`: desktop view showing the default deterministic analysis, supporting detail, and evidence coverage.
- `validated-ai-output.png`: desktop view showing a successfully validated structured AI response and collapsed Developer View.
- `mobile-evidence.png`: narrow-width view showing the supporting-detail and reconciliation experience.
- `ai-error-state.png`: sanitized AI failure state with deterministic results still available.

## Capture Standards

- Use representative non-sensitive data.
- Keep browser chrome out of the image where practical.
- Confirm there are no console errors or development overlays.
- Capture only genuine application states.
- Refresh these images whenever the corresponding UI changes materially.
